Le projet de démarrage est :

`Nkentseu.jenga`



\### Conclusion



La commande `jenga info` permet d'obtenir une première carte du workspace sans avoir besoin de lire le code source. Elle donne notamment les différents types de projets présents, les chaînes de compilation disponibles, le projet de démarrage et le fichier racine du workspace.
